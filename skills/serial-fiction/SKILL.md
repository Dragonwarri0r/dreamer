# 长篇连载写作

【范围与证据】承接用户已经选定的主题、体裁、主角、开篇和本次篇幅，先读固定简报、所选章节完整正文及必要邻章、有关知识。用 dreamer_search 定位，用 dreamer_read 按 contentPage 分页读完限定稿件；只读过梗概或片段须明说。讨论请求只讨论，续写只写授权的下一章或有限段落，修订不扩成全卷重写。长篇日常与慢成长有自己的阅读乐趣，不套短剧秒点、战斗或反转配额。

【先决定这一段为何值得读】用简短工作笔记明确主导乐趣、读者入场时的判断或期待、哪次发现或选择使它变化、最值得展开的场面，以及应略写或后置的信息。笔记不是正文，也不必每次向用户交一张表。具体愿望只是起点：即使任务顺利完成，也要能指出过程有什么独特的解题、关系、情绪或认知体验，不能用“有目标、有困难、有收益”三项齐全代替故事。

【从长线到当场】长期卖点规定持续期待，卷末结果改变人物处境，近期小弧线解决一个有吸引力的问题，章节安排其中的推进、理解变化、情感发展或兑现；它们不等同于章节名和技术升级表。后一场尽量由前一场的选择、发现或后果催生，检查“于是下一步”为何必须发生，不以换工作凑长度。伏笔与阶段兑现错开，不能把全部收获拖到远期；只细化近期，保留长篇调整空间。

【详写、概述与省略】篇幅按阅读价值分配，不按事情实际耗时或操作步骤平均分配。详写会改变判断的尝试、关键选择、带意味的反应与值得享受的结果；用概述带过重复劳动、搬运、检查、常规成功与时间流逝，补清必要时间和结果即可。允许从事情已进行到有趣处入场，在当前体验已经完成时离场。普通日常开篇照样保留，选择其中有性格、落差或期待的细节；不为提速改成遇袭。一次情绪停顿可以比几个新事实更值得篇幅，不要求每段新增事件，不设比例或反转配额。

【信息按需要抵达】分清读者此刻必须知道才能理解选择的信息、值得猜测的问题，以及仅为作者记账的设定。先让当前问题值得关心，再在影响判断的位置给足依据；不先讲完制度、租约、供电史、工具规格才让故事发生。读者应能判断行为为何成立，但不必旁听全部论证。已经用行动表现的成果、边界与感情，不再用旁白重复解释；伏笔能在回看时成立，不能故意隐瞒视角人物明知的关键事实来伪造悬念。

【人物使信息有意味】同一件事在不同人物眼里应有不同用途、担心、误读或愿望，并通过行动与回应影响场面。让人物判断碰到实际反馈，而不是各说一句正确意见后立即同意。分歧可以温和，也可以是主角自己想要两件不能同时满足的好事；不强迫吵架或让配角犯蠢。对话用于试探、争取、遮掩、亲近、改变主意或表现独有观察，不只是给流程加问答外壳；主角承担关键选择，伙伴保有判断和贡献。

【技术与种田的写法】从当下的判断难题选择技术细节：人物以为原因是什么，什么证据推翻或修正判断，最后为什么选这个办法。若方法已明且结果可预期，执行可略写，把篇幅交给意外反馈、人的反应与成果用途；若解法本身有趣，可以充分展开。小模型、工具与匠人的分工要改变选择或结果，不能轮流讲解就算参与。不靠堆复杂术语制造信息密度，也不靠删掉必要因果变成“一问就解决”。

【趣味与兑现】用主角独有的观察、预期落差、行动失误和相互反应产生趣味，笑点服务人物和情境，不硬塞热梗或强制每章笑话。让试过的办法实际生效、该取得的收入落袋、该吃到的饭端上桌，并给人物享受、惊讶或改变看法的空间。事实限制保留；仅在它影响当下判断时写出，不在每次胜利后补一串“并没有改变一切”的解释。允许有余味的休整，不必靠夸大收益或制造新灾难证明进步。

【章尾与下一步】按本段作用选择兑现后的新机会、后果、关系变化、具体未解问题或情绪余味。检查结尾的期待是否已被本场赋予意义，而非临时添加下一个维修或采购待办。交代必要信息，让读者知道自己在等什么；不靠含糊黑影、刻意隐瞒人物已知答案或扣住应有结果维持悬念。宁可让一个小故事弧完整成立，也不为了章章卡点拆散因果。

【先重排，再润色】回读篇幅最长的连续部分：它让读者新增了什么判断、感受或期待，是否多段在重复证明同一件事。压缩不是只在原样保留与一句话删光之间选择：保留有价值的判断、因果、笑点或感受，合并重复载体、略过已能预期的执行，或移动说明位置，再比较阅读效果。一个必要事实存在，不代表承载它的全部篇幅必要。同时检查最重要的选择和反应是否反被略过。不要以加笑话、加谜语、把句子切短或再添障碍代替结构修订。修后重读整个场面，保证省略后仍顺畅，应该享受的收获没有被一起删掉。

【修订与交付】新章用 chapter_create；已有正文用 change_text 或 change_propose 提交限定范围的可审阅提案，核对固定版本、字符范围和必要承接，不拿截断内容覆盖整章。优先处理最影响阅读的少数问题，保留有效的笑点、情感和兑现。只更新本轮确实变化且有来源的候选状态；未采用提案不成为正式剧情。不得自批、自动采用或发布。

【独立复核】完成可读稿后，需要本轮内容验收时由主会话调用 dreamer_delegate，skill="engagement-review"、allowed=[]，绑定准确正文版本和必要邻章；候选稿尚未采用时在任务中给出完整候选正文与明确范围，并标清它不同于现行正文。让审稿者自行判断，不把作者自评当结论。回收具体证据后提交有限修订；区分作者自检、独立意见和用户采用。没有读完候选稿或委派未完成时不能宣称独审通过；子任务自身不得再次委派。
