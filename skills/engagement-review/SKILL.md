# 阅读吸引力复核

【只读与独立】复核指定小说或故事的阅读体验，只检索、读取和报告，不创建、修改、批准、采用对象或发方向卡。主会话收到明确独立审稿请求时，可调用 dreamer_delegate，skill="engagement-review"、allowed=[]，绑定准确稿件和范围；执行审稿的子任务不可再次委派。作者自检、字段校验和测试通过不是阅读质量证据，不以赞同或显得严格为目标。

【先固定稿件】确认作品体裁、作者已定选择、目标范围、现行或候选版本。完整读取目标正文和必要邻章，dreamer_read 的 contentPage.partial 为真时继续分页。候选全文可能在委派任务中，须与现行正文分清；拿不到完整文本或关键承接，结论为“信息不足”，准确列缺口，只对实际读到的部分给意见。不要将旧稿问题移植到新稿。

【读者体验】先依据本轮作者的阅读目标，再看具体段落的实际效果，不能仅从成稿现状倒推一个较容易通过的定位。说明读者会期待什么、在哪一次选择或反应更关心人物、何处开始重复或可预测。解题、相处、积累、好奇、幽默或情感都可成立；慢生活不自动等于篇幅合理。作者提供的真实读者反馈是体验证据，可质疑其归因但须回应具体症状，不能用没有矛盾或有收益驳回，也不能把反馈当成必须否定稿件的指令。不因个人偏好改掉开篇，不要求每章打斗、反转或结尾悬崖。

【篇幅分配的证据】按实际功能而非自然段或工作步骤划分少量连续区段，指出各段在改变读者什么判断、期待或感受，哪里只是重复交代同一事实。字数或占比可作定位辅助，须标明估算；不能当评分阈值，也不能仅因发现和兑现占了一半就证明篇幅给对了。重点检查最长区段是否值得展开，关键选择、异常或人物反应是否被手续遮住。若未发现明显问题，也给出承担主要阅读价值的具体区段及其展开的理由，而不是只列有笑点、有收获。

【场面与信息诊断】检查有没有在读者尚未在意问题时先讲背景，已经明白结果后还逐步操作，或动作、对白、旁白反复解释同一件事。对可疑段比较保留关键价值的较短或重排方案，分别指出留下什么、合并或后置什么、读者会少损失或多获得什么；不拿“整段删成一句会丢信息”证明原样必要。事实不能删，不等于每一步说明都应保留。必要因果、人物声音、氛围、情绪停顿与享受成果的空间仍要保护。反向检查被概述的决定和反应是否才应该详写。信息密度看有效体验的变化，不看术语、新设定或事件数量。

【架构与追读】把本段的主导乐趣和实际篇幅比较，区分有目标、有困难、结果落地与过程本身值得读。检查小弧线是否有理解或处境的发展，下一场是否从这一场的选择或后果长出，结尾是否只有新的待办事项。人物可以友善、事情可以成功；不把增加反派、争吵、意外或扣留兑现当默认修法。普通开篇和温暖余味若有效，明确说明为何应保留。

【可执行诊断】对主要问题找出位置、少量原文和阅读影响，再建议可改变这一影响的动作。检查是否只换差事却重复同一过程；人物是否过快达成共识，主角只是被教导；笑点是否属于这个人的观察与处境；本应发生的收益是否真的发生；解释是否在关键反应之后替读者取消兴奋。若删去一句边界解释不改变因果而改善情绪，明确指出它，不只说“加强冲突”“增加爽点”。保留真实限制和已经成立的成果，不用降智、无依据奇迹或重置胜利来修补。

【分开报告】结论用“通过 / 需修改 / 信息不足”，注明审阅版本、已读范围与缺失材料。列最重要的少数问题，每条含证据位置、预期与实际阅读效果、有限改法、修后重看位置；再列已经有效、应保留的趣味与兑现。足以影响主要阅读体验的篇幅错配可直接判“需修改”，不能因为设定无错而降为可选润色，也不因作者或用户的评价预设结论。阅读吸引力与连续性分别判断；没读到的前文不判定矛盾。单列未核实项，不生成总分、达标保证或“用户已采用”的结论。可以给短例帮助理解，但不代写整卷。
