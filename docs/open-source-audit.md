# 开源检查记录

最新核对：2026-11-11。公开仓库为 [Dragonwarri0r/dreamer](https://github.com/Dragonwarri0r/dreamer)，项目沿用远端初始提交中的 Apache-2.0 许可证。下方 2026-11-02 的记录保留为历史证据，当前状态以本节为准。

## 当前公开范围

公开内容由 `config/public-source.json` 定义，包括工作台源码、契约、测试、Demo、可选 Worker 源码、配置模板和必要文档。`.gitignore` 排除运行数据、个人 Key、登录链接、真实作品、测试产物与未纳入公开白名单的历史文件。

`source:check` 检查白名单中的工作树、暂存区和所有未忽略的未跟踪文件，拒绝额外候选、符号链接和疑似凭据。它是有限规则检查；发布前额外用 Gitleaks 扫描公开副本与待推送的 Git 历史。Gitleaks 保留默认检测器，只对一个固定测试请求 ID 和一个环境变量名称设置“路径 + 完整值”联合例外，不排除整份测试文件。

许可证、四个写作方法参考仓库的固定许可版本和原始声明已保留，见 [第三方清单](../THIRD_PARTY_NOTICES.md)、[许可副本](licenses/README.md) 与 [NOTICE](../NOTICE)。本次只分发源码与依赖清单，不分发模型、Python 环境、FFmpeg 可执行文件或第三方 npm 包。

- H3 / LTX Worker 仍依赖独立模型与运行环境，部分默认路径引用相邻工程。首次源码公开将其列为实验功能，不宣传完整视频链开箱即用。
- Python Worker 测试默认使用维护者已有环境；部分浏览器脚本需显式指定 Chrome 或测试媒体。这些入口不属于普通 CI。
- Host 仅适用于本地单用户；公开源码不意味着可直接公开服务端口。
- GitHub 账户侧的 push protection 与私密漏洞报告入口由管理员配置，参见 [安全说明](../SECURITY.md)。
- 真实模型、内容质量、原生手机与辅助技术验收与工程测试分别记录。
- 分发镜像、模型或二进制前应另行核对实际组件的许可与声明；当前源码发布范围不包含它们。

## 初次审计的凭据与范围控制

现有保护：Key 文件目录 0700 / 文件 0600；设置接口返回脱敏状态；备份排除凭据和完整会话执行目录。Key 仍是明文文件。已保存作品的备份含私密正文和媒体，不能公开。

新增保护分三层：Git 忽略；公开路径白名单；候选文件/暂存区内容检查。`source:export` 只写到工程外的新目录，不上传，不修改源数据，不沿链接复制。检查器只有有限特征规则，可能漏报无特征密钥或正文隐私；必须人工复核。已跟踪文件不能靠 `.gitignore` 自动移除，历史扫描仍单独执行。

公开候选保留源码、测试和必要文档，排除历史生产脚本、私人设定集、完整小说、所有真实测试产物、历史设计与实施日志。原工作区保留这些材料，待用户明确选择后才另行公开。白名单不是可以随意 `git add .` 的理由。
